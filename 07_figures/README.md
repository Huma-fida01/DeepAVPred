## Original data correspondence

Both plotting scripts load 1,088-row label and score files, consistent with pooled outputs for the AVPtrain dataset. The feature-specific pairs are:

- CPSR: `DeepBiGRUytest.csv` and `DeepBiGRUyscore.csv`
- ExPseAAC: `DeepBiGRU_PseAACytest.csv` and `DeepBiGRU_PseAACyscore.csv`
- RECM: `DeepBiGRU_RECMytest.csv` and `DeepBiGRU_RECMyscore.csv`
- RECM-DWT: `DeepBiGRUytest_DWT.csv` and `DeepBiGRUyscore_DWT.csv`

For the ROC legend, `ROC_PR_Curve_New.py` reads the summary AUC values from `DeepBiGRUtrain_results.csv`, `DeepBiGRU_PseAACtrain_results.csv`, `DeepBiGRUtrain_results_RECM.csv`, and `DeepBiGRUtrain_DWT.csv`, respectively. `PR_Curve_New.py` calculates average precision from each label/score pair.

The independent-test files named `ytest_sum_*_ind.csv` and `yscore_sum_*_ind.csv` are not referenced by either surviving plotting script. Therefore, despite `Test` appearing in two PNG filenames, the preserved figures are not documented here as AVPtest independent-test plots.

## Combined Figure 1 notebook

`AUC_ROC UPD(1).ipynb` is the surviving Jupyter notebook that combines the two analyses into a single two-panel figure. Panel A reproduces the ROC analysis implemented separately in `ROC_PR_Curve_New.py`, and panel B reproduces the precision-recall analysis implemented separately in `PR_Curve_New.py`. The notebook uses the same four 1,088-row AVPtrain label/score pairs and the same four training-result CSVs listed above.

For ROC, the notebook calculates the curve coordinates with `roc_curve` using column 0 of each saved label and score matrix, while it reads the displayed AUC from row 10, column 8 of the corresponding training-result CSV (falling back to the last cell if that position is unavailable). For PR, it calculates precision and recall with `precision_recall_curve` and AP with `average_precision_score`, again using column 0.

The notebook writes `DeepAVPred_Combined_Figure_HighQuality.svg` and `DeepAVPred_Combined_Figure_HighQuality.png`. Its saved notebook output shows the same AUC and AP values reported for manuscript Figure 1. It does not reference any `*_ind.csv` file and provides no generating-code evidence about the incomplete 119-row independent-test exports.

## Manuscript correspondence

The final manuscript identifies these analyses as Figure 1: "Receiver operating characteristic (ROC) and precision-recall (PR) curve analysis using different feature-encoding schemes." Panel A contains the ROC curves, and panel B contains the PR curves for CPSR, ExPseAAC, RECM, and RECM-DWT. The AUC and AP values stated in the manuscript match those displayed in the surviving figures.

**Reproducibility note:** The notebook requires historical per-sample score/label CSV inputs that are not distributed in this repository; the included figures are archived visual artifacts, not regenerated by the public package.
